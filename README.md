A [make.fun](https://make.fun) bounty entry: one funny line, written by a
pure-stdlib Python program.

## The line

> My Roomba escaped, filed for emancipation, and now sends me postcards
> from the neighbours' house.

## How it works

`main.py` writes that single self-contained joke (97 characters, one line,
UTF-8) to `/output/entry.txt`. No dependencies, no network, deterministic:
every run produces the exact same bytes.

```sh
python3 main.py
```
